# Template: Listicle (3–5 produk)

**Kapan dipakai:** tema kumpulan ("kado anak di bawah 100rb", "5 khimar adem buat harian"). Bagus untuk disimpan & dibagikan.

## Struktur
Threads membatasi 500 karakter per posting, jadi listicle ditulis sebagai **utas**:
- Posting 1: hook + janji isi ("5 mainan edukatif di bawah 100rb, no. 3 favorit 👇")
- Posting 2–4: masing-masing 1–2 produk + alasan singkat + link (maks 3 link per posting)
- Posting terakhir: rangkuman + pertanyaan

> Catatan: Buffer bulk upload hanya mendukung posting tunggal. Untuk utas, CSV cukup berisi **posting 1 tanpa link** yang memancing komentar, lalu Intan menambahkan reply berlink secara manual di Threads, atau buat utasnya langsung di composer Buffer (bukan bulk).

## Contoh posting 1 (bisa masuk CSV)
```
Kado ulang tahun anak 2–4 tahun di bawah 100rb, yang nggak cuma dipakai sekali 🎁

1. Busy book
2. Balok kayu
3. Puzzle angka
4. Buku stiker reusable

Mau aku kasih link yang reviewnya bagus? Komen "mau" ya bun 👇
```
